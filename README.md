# Bluefox / TMPA Chat

Aplikasi mobile berbasis web dan Capacitor yang dirancang untuk memberikan pengalaman interaksi yang cepat, responsif, dan terintegrasi penuh.

## Fitur Utama
- Antarmuka pengguna modern yang bersih menggunakan Tailwind CSS.
- Integrasi kecerdasan buatan untuk membantu berbagai kebutuhan produktivitas.
- Sistem manajemen data aman yang terhubung dengan Supabase.
- Dioptimalkan khusus sebagai aplikasi Android native menggunakan Capacitor.

## Cara Instalasi di Android
1. Unduh file `app-debug.apk` atau file rilis dari halaman **Releases**.
2. Buka file APK tersebut di perangkat Android Anda.
3. Berikan izin instalasi dari sumber tidak dikenal jika diminta oleh sistem.
4. Selesaikan proses instalasi dan jalankan aplikasi.
